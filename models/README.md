# Model 3D cho web

| File | Nội dung |
|---|---|
| `m-host-grotesk.glb` | Chữ **M** 3D, font Host Grotesk VN Medium, đùn khối dày 0.32, bo cạnh tròn, màu `--red #ff1d12` (PBR, metallic 0.15, roughness 0.32). Cao 1 đơn vị, tâm ở gốc, mặt trước nhìn về +Z. |
| `m-host-grotesk.webp` | Ảnh poster 1200px (hiện khi đang tải / làm ảnh dự phòng). |

Dựng lại hoặc dựng chữ khác: `python tools/glyph3d.py M models/m-host-grotesk.glb` (xem tuỳ chọn trong `tools/glyph3d.py`).
Font gốc: Host Grotesk, SIL OFL 1.1 — model là sản phẩm từ font nên dùng thương mại thoải mái.
