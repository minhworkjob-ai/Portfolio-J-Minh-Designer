Quên mật khẩu?

Tính năng này dùng Firebase Authentication của Google. Cần cấu hình một lần:

  1. Mở console.firebase.google.com → Add project.
  2. Build → Authentication → Get started → bật Email/Password, Google và GitHub (GitHub cần Client ID/Secret của một OAuth App).
  3. Authentication → Settings → Authorized domains → thêm minhworkjob-ai.github.io.
  4. Project settings → Your apps → Web (</>) → chép đoạn firebaseConfig vào mục firebase trong site.config.json (apiKey, authDomain, projectId, appId), rồi chạy node build.mjs và đẩy lên GitHub.
