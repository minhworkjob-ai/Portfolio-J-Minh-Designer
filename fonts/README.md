# Host Grotesk VN

Font tiêu đề của web: bản Việt hoá của **Host Grotesk** (© 2023 The Host Grotesk Project Authors,
https://github.com/Element-Type/HostGrotesk), giấy phép **SIL Open Font License 1.1** (xem `OFL.txt`).

Đã thêm: dấu hỏi, dấu nặng, móc (ơ ư) và 88 chữ có dấu tiếng Việt, dựng bằng `vietize.py`
(fontTools). Font phái sinh được đổi tên thành "Host Grotesk VN" và vẫn theo giấy phép OFL 1.1.

Tạo lại: `python vietize.py "HostGrotesk[wght].ttf" 400 HostGroteskVN-Regular.woff2` (và 500 cho Medium).
